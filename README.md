📊 Social Media Analytics Ecosystem (2023–2025)

An end-to-end Power BI dashboard project analyzing multi-platform social media performance across LinkedIn, Instagram, TikTok, Facebook, and X from 2023 to 2025.

This interactive report consolidates raw exports from five platforms into a unified analytical model, transforming engagement metrics into strategic insights.

🔧 Technical Implementation

Advanced Power Query (ETL): Cleaned, normalized, and merged raw API exports into a standardized schema.

Dynamic Data Modeling: Designed a scalable star schema with a central Fact table and optimized Dimension tables for efficient cross-filtering.

Custom DAX Measures: Built advanced calculations including:

Average Engagement Rate

Year-over-Year (YoY) Growth

Rolling Totals & Trend Analysis

📈 Key Insights Delivered

Executive Overview:
Centralized tracking of 43M+ impressions and 38M+ likes across platforms for quick performance evaluation.

Content Intelligence:
Identified high-performing content patterns and engagement drivers using trend analysis and word cloud visualization.

Trend Forecasting (2023–2025):
Analyzed posting performance trajectories to predict optimal posting windows and platform-specific content shifts.

🚀 Project Impact

This project demonstrates how data analytics transforms social media vanity metrics into actionable business intelligence. By combining strong data modeling, advanced DAX, and performance-driven visualization, the dashboard enables stakeholders to make informed growth decisions.
